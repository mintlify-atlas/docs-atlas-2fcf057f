## What's Running

This homelab hosts a growing suite of services across a structured IP space and domain (`home.arpa`):

| Service | URL | Purpose |
|---|---|---|
| Proxmox VE | `pve.home.arpa` | Hypervisor and VM/LXC management |
| Technitium DNS | `dns.home.arpa` | Internal DNS + adblocking |
| Nginx Proxy Manager | `npm.home.arpa` | Reverse proxy + SSL |
| Portainer | `portainer.home.arpa` | Docker container management |
| Dashy | `dashy.home.arpa` | Service dashboard |
| Tailscale | `ts.home.arpa` | VPN and remote access |
